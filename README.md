# 长征足迹 · 历史旧址三维展示

以主题封面和四个全屏旧址页面呈现长征相关历史建筑。Three.js 几何由代码生成，按提供的建模板近似还原主要轮廓、比例和识别特征；未展示的背面与内部结构采用简化推断。网站由天津大学「瑶湘呼应」实践队开发。

## 四处旧址

- **瑞金·临时中央政府旧址**：中央红军长征出发地，页面从 1934 年的战略转移讲起；建筑主体约 14 × 12 m。
- **遵义会议旧址**：两层砖木回廊、灰瓦屋面、红色栏杆与侧楼梯；主体约 24 × 9.5 m。
- **延安·岭山寺塔**：以中央红军 1935 年抵达陕北为时间节点，说明延安作为后续革命中心的历史承接；九层密檐砖塔高约 44 m。
- **会宁·会师楼**：以 1936 年红军会师为长征终章；会宁城墙约 50 × 20 m，楼体总高约 15 m。
- **模型说明**：瑞金旧址保留白色灰泥墙、绿色门窗、弧形山墙与红星徽记；遵义旧址为两层砖木回廊；会宁模型含城墙、中央拱门与双层木构楼阁。

## 运行

在项目目录启动静态服务器：

```sh
python3 -m http.server 8000
```

浏览器访问 `http://127.0.0.1:8000`。页面通过 import map 从 unpkg 加载 Three.js 0.169.0。

## 操作

- 滚轮、触屏上下滑动、键盘 ↑/↓ 或 PageUp/PageDown 在封面和四处旧址间切换，也可点右上方的页面导航。
- 模型页缓慢自动旋转；拖动时暂停，松开后恢复。按住 Alt 并滚动可缩放。
- 右下角按钮切换透视、正面、侧面与平面视图。

## 模型源码

- `src/createTower.js`：会宁会师楼

- `src/createTemporaryGovernmentSite.js`：临时中央政府旧址
- `src/main.js`：场景、镜头、模型装载与页面切换
